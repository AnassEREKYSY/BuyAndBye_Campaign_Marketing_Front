# Buy & Bye - Marketplace Frontend

React + TypeScript + Vite frontend application using Bun.

## Tech Stack
- React 18+
- TypeScript (strict mode)
- Vite
- Bun

## Architecture
Feature-oriented structure with DDD principles adapted to frontend.

## Getting Started

### Prerequisites
- Bun installed

### Installation
```bash
bun install
```

### Development
```bash
bun run dev
```

### Build
```bash
bun run build
```

### Preview
```bash
bun run preview
```

## Project Structure
- `src/app/` - Application bootstrap (routing, providers)
- `src/modules/` - Business modules (auth, users, products)
- `src/shared/` - Cross-cutting concerns (API client, utils, shared components)
